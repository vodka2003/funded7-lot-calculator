# ロット計算 — JPY

スマホから、銘柄・エントリー価格・損切り価格・損失額（円）を入力してロットを計算するWebアプリ。

- Funded7のFX24銘柄、XAUUSD、XAGUSD
- JPY口座 / 固定金額 / 0.01ロット刻み・切り捨て
- HTML / CSS / JavaScript。ライブラリ・ビルド・ログイン不要
- 発注、口座接続、残高比率、リスク通知なし
- 入力価格・損失額は外部に送信しない。端末には最後に選んだ銘柄のみ保存

公開URL: https://vodka2003.github.io/funded7-lot-calculator/

## 計算

1ロットの損失 = |エントリー価格 − 損切り価格| × 契約サイズ × 損益通貨→JPY換算レート

ロット = floor(指定損失額 ÷ 1ロットの損失 × 100) ÷ 100

0.01未満は計算不可として表示。銘柄の最大ロットを超える場合は最大値を適用。価格・通貨換算・ロット切り捨てはBigIntによる有理数計算。

銘柄仕様は[Funded7公式](https://funded7.com/faq/contract-specifications/)を参照（確認日: 2026-10-28）。FX契約サイズ100,000 / 最大100、XAUUSD 100 / 最大20、XAGUSD 5,000 / 最大20。0.01刻みは利用者の指定。

JPY以外の損益通貨は[Coinbase公開API](https://docs.cdp.coinbase.com/coinbase-app/track-apis/exchange-rates)から、計算ごとにUSD基準レートを取得。JPYレート÷損益通貨レートで換算。画面の時刻は**取得時刻**であり、配信元の更新時刻ではない。APIに更新タイムスタンプはなく、Funded7と同一レートやティック単位の即時更新は保証しない。取得失敗時は計算結果を表示しない。日次レートへの自動フォールバックや永続キャッシュは使わない。

入力変更・銘柄変更・他アプリへの切り替え時に結果を隠し、古い条件の結果を使わないようにする。売買方向はSLの位置から表示。

手数料・スワップ・約定滑りは含まない。入力には実際の注文価格・SL価格を使用する。レバレッジや証拠金可否、プロップのルール判定は扱わない。

## 開発

Node.js 20以上（追加パッケージ不要）:

```sh
npm test
npm start
```

http://127.0.0.1:4173/ で確認。

## 公開

GitHub Pages: `main` ブランチの `/` を公開元に設定。コミットをpushすると更新される。

iPhoneのSafariで公開URLを開き、「共有」→「ホーム画面に追加」で利用可能。為替換算にはインターネット接続が必要。
